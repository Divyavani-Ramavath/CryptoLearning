# CryptoLearn

AI-Powered Adaptive Cryptocurrency Learning and Decision-Making Simulation Platform

## Description

CryptoLearn is an educational platform that helps beginners learn cryptocurrency concepts through interactive lessons, quizzes, scenario-based decision making, and virtual paper trading.

The platform analyzes learner performance and provides personalized learning recommendations.

## Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- Prisma
- AI API
- Chart.js
